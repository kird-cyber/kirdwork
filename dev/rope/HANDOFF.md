# 로프 연습장 — 인수인계 (웜즈식 게임 1단계: 로프 손맛 확인)

주소: https://kird-cyber.github.io/kirdwork/rope/ · 소스: `dev/rope/` · 빌드: `python3 build.py` → `dist/index.html` → 저장소 `rope/index.html`로 복사

## 목적
웜즈식 게임(이름 미정)을 만들기 전에 닌자 로프 손맛을 먼저 확인하는 연습장. 사용자가 "손맛 조절" 패널에서 찾은 값을 본 게임에 넣는다.

## 구조
- `config.js` 손맛 수치(ROPE_DEFAULT)·프리셋(2세대/3세대/날다람쥐)·슬라이더 목록
- `core.js` 포격리스와 같은 결정적 수학(난수·삼각함수 표)
- `mapgen.js` 코스 맵(3600×1800, 바다 1700 아래, 체크포인트 6개 + 도착)
- `sim.js` 결정적 물리: 매 틱(1/120초) 키 입력 비트로 진행. 걷기·점프·백덤블링, 로프 발사(줄이 날아감)·매달림(길이 제약)·감기(각운동량 보존 → 감으면 빨라짐)·벽 반동·모서리 감김/풀림. 입력은 RLE로 저장 → 유령 재생, 온라인에서도 그대로 쓸 수 있음
- `main.js` 그리기·입력·HUD·패널·유령·시범 보기
- 시험: `node tests/sim.test.js`(지형·로프·재생 일치·무작위 4만 틱), `node tests/solve.js 24 140`(빔 탐색으로 코스 완주 증명 → `tests/out/solution.json` = 시범 유령, 빌드에 포함). **맵이나 기본 수치를 바꾸면 solve.js를 다시 돌릴 것**(시범 유령이 기본 수치로 기록됨).

## 표적 연습 모드 (오른쪽 위 파란 버튼 / M키)
- `weapons.js`(결정적): 무기 8종 = 바주카(파워·바람), 수류탄(파워·타이머 1~5초·튕김), 클러스터(작은 폭탄 5개), 샷건(즉시·직선), 다이너마이트(발밑/로프에서 투하·5초), 지뢰(1초 뒤 작동·근접 폭발), 공중 폭격(맵 클릭 목표·5발), 야구 방망이(근접 날리기). 폭발은 지형을 파고(mask) 표적·지렁이를 날림(로켓 점프 가능), 앵커 바위가 사라지면 로프 풀림.
- 조작: Tab/우클릭/무기 버튼 = 무기판, 숫자 1~8, F/좌클릭/공격 버튼(파워 무기는 누르고 있다 떼기), 마우스 조준, Q/E 타이머. UI 명령은 stepRun의 `cmd`({w,fuse,aim,face,tx})로 들어감(온라인 때 그대로 전송 가능).
- 표적 12개(허수아비 과녁, 체력 100): 체력 0이면 격파, 바다에 빠지면 격파. 전부 부수면 기록.
- 캐릭터: 원작 웜 디자인을 베끼지 않은 **자체 지렁이**(마디 링·환대 띠·빨간 머리띠·작은 눈). 사용자가 원작과 최대한 비슷하게 원했으나 Team17 캐릭터 디자인 복제는 하지 않기로 함.
