# 연구부정 소탕전 기록 서버 만들기 (구글 시트, 약 5분)

케이요새 「연구부정 소탕전」의 순위·명예의 전당을 구글 시트에 저장합니다. 비용은 없고, 관리자는 시트에서 기록을 직접 보고 지울 수 있습니다.

## 1. 시트 만들기
1. 기관에서 쓸 구글 계정으로 [sheets.new](https://sheets.new) 를 엽니다.
2. 시트 이름을 `케이요새 기록` 처럼 바꿉니다. (탭은 따로 만들 필요 없음 — 첫 기록이 들어올 때 「기록」·「닉네임」 탭이 자동으로 생깁니다.)

## 2. 스크립트 붙여 넣기
1. 메뉴 **확장 프로그램 → Apps Script** 를 누릅니다.
2. 편집기에 있는 `Code.gs` 내용을 모두 지우고, 이 폴더의 **Code.gs** 파일 내용을 통째로 붙여 넣습니다.
3. 저장(💾 또는 Ctrl+S).

## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**.
2. 톱니바퀴(유형 선택) → **웹 앱**.
3. 설정:
   - 설명: `케이요새 기록`
   - 다음 사용자로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (로그인 없이 게임에서 기록을 보내야 하므로)
4. **배포** → 권한 승인 창이 뜨면 계정을 고르고 "고급 → (안전하지 않은 페이지로) 이동 → 허용". 내가 만든 스크립트라 뜨는 경고입니다.
5. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 4. 게임에 연결
- 복사한 URL을 개발 담당(Claude)에게 알려 주면 `src/solo.js`의 `SOLO.boardUrl`에 넣고 다시 배포합니다.
- 넣기 전에 바로 시험해 보려면 게임 주소 뒤에 `?board=웹앱URL` 을 붙여 열면 됩니다.

## 관리
- 「기록」 탭: 도전 한 번이 한 줄(시각, 날짜, 닉네임, 결과, 쓴 시간(초), 남은 체력, 격파, 탱크, 발사, 버전, 입력 기록, 남은 적 체력).
  - 결과: `클리어`(3대 소탕 · 쓴 시간이 적을수록 위) / `시간종료`(10분 다 씀 · 남은 적 체력이 적을수록 위, 항상 클리어 아래) / `탈락`(내가 격파됨 · 순위 없음, 통계용).
  - 지난 날 기록도 지우지 않는 한 계속 남습니다. 게임 화면에는 상위 10명만 보입니다.
  - 부정 의심 기록은 그 줄을 지우면 순위에서 바로 빠집니다.
  - `버전` 칸이 `v2/ok`가 아니면(예: `v2/mismatch`) 게임이 스스로 다시 돌려 봤을 때 결과가 달랐다는 뜻입니다.
  - 의심 기록은 `입력 기록` 칸 내용으로 다시 돌려 검증할 수 있습니다(`node tests/verify_solo.js`).
- 「닉네임」 탭: 닉네임과 PIN 확인용 키(PIN 자체는 저장하지 않음). PIN을 잊은 사람은 이 줄을 지우면 다음 기록 때 새 PIN으로 등록됩니다.
- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 해야 반영됩니다(URL은 그대로).

## 개인정보
- 저장하는 것: 닉네임, PIN에서 만든 확인용 키(되돌릴 수 없음), 기록 수치, 게임 입력 기록.
- 실명·사번·이메일은 받지 않습니다. 화면에서도 실명 대신 닉네임을 쓰도록 안내합니다.
