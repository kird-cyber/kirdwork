# 포격리스 — 인수인계 노트 (새 대화에서 이어 작업할 때 먼저 읽기)

플레이 주소: https://kird-cyber.github.io/kirdwork/  ·  저장소: kird-cyber/kirdwork (`index.html` = 배포본, `dev/` = 개발 소스)

## 한 줄 요약
포트리스2 감성의 턴제 포격 게임. 친구끼리 링크로 접속(로그인 없음, 닉네임만), 최대 4:4. 단일 HTML, 서버 비용 0원.

## 확정된 결정 (사용자 요청)
- 이름 **포격리스**, 주소는 그대로. 로그인 없음, 닉네임 표시. 누구나 방 생성, 대기방에서 팀 선택(←→), 위치는 무작위.
- 궤적선 없음(각도기만). 턴 60초. 시간 1초당 딜레이 +4. 이동력은 초기값 대비 +30%.
- 상대 차례엔 파워·각도 숫자 비공개, 포신 움직임만 보임. 아래 조작판은 항상 내 탱크.
- 피격 범위: 피해 반경 = 무기 반경×1.8 + 몸통 30px, 가장자리 30%. 땅 파임은 ×1.15. 맵 두께 1.5배. 포탄 그림 2.1배.
- 사거리: 풀파워 약 3,000px(maxSpeed 1340). 시작 거리 최대 2,400px(1:1·2:2), 최소 900px.
- 해프닝: 운석/지진은 판 시작 때 50% 확률로 판 내내. 토네이도/불기둥은 3턴째부터 무작위로 생겨 3~4턴 뒤 사라짐.
- 서든데스: 10 + 4×인원 턴부터 매 턴 체력 4% 감소, 바람 강화.
- 탱크 8종 + 히든 **케이**(회사 로고 색 파랑 #2E86D6 + 연두 #8CC63F, K자 날개). 직접 선택 불가, "?" 랜덤 시 1/9 확률. 무기: K-바운스탄(한 번 튕김), K-분열탄(정점에서 두 갈래).
- 리플레이 기능은 필요 없음(사용자 결정).
- **턴 넘기기**(원작식, 사용자 결정): 주황 버튼/P키. 쏘지 않고 넘기면 딜레이 = 기본×1/4 + 이동·아이템·시간. 차례는 **딜레이만으로** 결정(따로 고르는 연속 사격 없음) — 상대 턴이 비싸면(이동·2번 무기·오래 고민·느린 탱크) 자동으로 연속 턴, 배너 "또 내 차례!". 버튼 아래 글씨에 '넘겨도 바로 다시 내 차례'/'딜레이 +N' 미리보기. `CONFIG.turn.pass.delayMul`, sim `cmdPass`·`passCost`·`passGetsTurnBack`. 딜레이 숫자(기본 580~900, 이동 0.6/px, 시간 4/초 등)는 원작 공개 수치가 없어 자체 값.
- 이동력이 0이 돼도 ← →로 방향(포신 방향)은 돌릴 수 있음(위치는 고정). 각도 ↑↓는 원래대로 가능.
- 게이지(파워) → 거리는 **원작처럼 제곱 관계 유지**(비례로 바꾸지 않음, 사용자 결정). 대신 **모든 탱크 각도 0~88°로 통일**(사용자 결정)해 원작식 고각 각샷(파워 고정 + 각도 조절)이 가능하게 함. 탱크 차이는 무기·체력·이동력으로만.
- 포탄 고증(사용자 결정): 무기마다 전용 그림·연출(`src/shells.js`). 해머 1번=검콩(크고 검은 쇠공), 2번=빨콩(작고 빨간 고폭탄, 피해 반경 좁고 위력 큼: 반경 24·피해 564). 볼더 2번은 '불바위'(불붙은 바위), 트래퍼 1번은 '수류탄'(핀이 튐). 화살·볼트는 맞은 자리에 잠깐 꽂혀 있음.
- 케이는 탱크 선택 화면에 원래 색으로 표시하되 고를 수 없음("? 랜덤 전용" 배지). 누르면 정보만 보임.
- 탱크 정보 카드(대기방·연습 설정 공통, `main.js` tankCardHTML): 탱크를 누르거나(PC는 마우스만 올려도) 체력·방어·이동력·속도 막대, 특성, 1번·2번 무기 설명(`WEAPON_DESC`)과 피해·반경·바람·중력·재사용·딜레이 표시. 무기를 추가하면 WEAPON_DESC에도 한 줄 넣을 것.

## 구조 (dev/src)
`config.js`(모든 수치) · `core.js`(난수·삼각함수 표) · `mapgen.js`(맵 8개) · `sim.js`(게임 계산, 결정적) · `controller.js` · `audio.js`(효과음·음악 합성) · `shells.js`(무기별 포탄 그림·꼬리·입자, look.shape로 선택) · `render.js`(그리기 전용) · `bot.js`(연습 봇 + 밸런스 측정 봇 'measure') · `mqtt.js`(MQTT 클라이언트) · `net.js`(방 프로토콜) · `online.js`(홈·대기방·온라인 동기화) · `main.js`(HUD·연습·튜토리얼·결과) · `template.html`
- 빌드: `python3 build.py` → `dist/index.html`(배포용), 문법 오류가 있으면 빌드 실패.
- **결정성 규칙**: sim/mapgen에서 Math.sin/cos/pow/atan2 금지(표·sqrt만). 모든 기기가 같은 계산을 하고 입력(TurnInput)만 주고받음. 상태 해시로 검증, 어긋나면 기록으로 재구성.
- 온라인 중계: 무료 공개 MQTT(EMQX → HiveMQ → mosquitto 순 시도). 발사 기록은 QoS1, 멈춤 감지 시 재요청, 방장 승계, 끊겼다 돌아오면 기록 복구, 팀 전원 이탈 30초면 기권패.
