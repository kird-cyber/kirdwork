# KIRD 나눔마켓 — 내 컴퓨터에서 고치고 다시 연결하기

이 묶음 하나로 나눔마켓 홈페이지(직원 입찰 화면, 관리자 화면)와 구글 시트 서버 코드를 모두 고칠 수 있습니다.
빌드 도구나 설치할 프로그램은 없습니다. 메모장이나 VS Code로 고치면 됩니다.

## 폴더 구성

```
market/
├─ index.html          직원 입찰 화면 (글자·배치)
├─ admin.html          관리자 화면 (글자·배치)
├─ config.js           ★ 서버 주소(api) — 연결은 여기만 바꾸면 됨
├─ assets/
│  ├─ app.css          공용 색·글꼴·버튼 (맨 위 :root 의 색 값)
│  ├─ client.js        서버 연결, 안내 문장(rulesText), 데모 예시 상품
│  ├─ bidder.js        입찰 화면 동작
│  ├─ admin.js         관리자 화면 동작
│  ├─ core.js          ★ 입찰 규칙 전부 (금액 단위, 재입찰, 마감, 코드 확인…)
│  └─ k.png, kmark.png 로고
└─ apps-script/
   ├─ gas.js           구글 시트에 읽고 쓰는 부분
   ├─ Code.gs          ★ Apps Script에 붙여 넣는 파일 (core.js + gas.js 를 합쳐 자동 생성)
   └─ 설치안내.md       구글 시트·웹 앱 처음 설치하는 법
dev/market/            테스트와 Code.gs 만드는 스크립트 (고급)
```

## 1. 내 컴퓨터에서 열어 보기

- 가장 쉬운 방법은 `market/index.html`을 크롬으로 끌어다 놓는 것입니다. `config.js`의 서버 주소로 바로 연결됩니다.
- 서버와 상관없이 화면만 고쳐 보고 싶다면 `config.js`의 `api`를 `''`(빈 값)로 바꾸세요. **데모 모드**가 되어 입찰이 내 브라우저에만 저장됩니다.
  - 체험 코드: `TEST-AAAA`
  - 관리자 비밀번호: `demo`
- 파이썬이 있다면 웹 서버로 여는 쪽이 더 정확합니다. `market`의 상위 폴더에서 `python -m http.server 8000`을 실행하고 http://localhost:8000/market/ 으로 들어가세요.

## 2. 자주 고치는 곳

| 하고 싶은 것 | 고칠 파일 |
|---|---|
| 행사 이름·안내 문구·마감 시각·재입찰 방식·입찰 단위 | **코드 수정 필요 없음** — 관리자 화면 「입찰 규칙·설정」 |
| 화면 문구 (예: 「참여 방법」 3단계) | `index.html` |
| 규칙 안내 문장 | `assets/client.js`의 `rulesText` |
| 색 | `assets/app.css` 맨 위 `:root` (`--kird` = 기본 파랑, `--comp` = 경쟁입찰 주황, `--seal` = 일반입찰 보라) |
| 로고 | `assets/kmark.png` 바꾸기 (같은 이름으로) |
| 입찰 규칙 자체 (계산 방식 등) | `assets/core.js` → **반드시 3번도 할 것** |

## 3. 규칙(core.js)이나 시트 쪽(gas.js)을 고쳤다면

서버(Apps Script)도 같은 규칙으로 돌아야 합니다. 두 파일을 고친 뒤에는 아래 순서를 따르세요.

1. `Code.gs`를 다시 만듭니다.
   - 파이썬이 있으면 상위 폴더에서 `python dev/market/build_gas.py`를 실행합니다.
   - 파이썬이 없으면 `Code.gs` 맨 위 설명 3줄을 남기고, 그 아래에 `core.js` 전체와 `gas.js` 전체를 순서대로 이어 붙입니다.
2. 구글 시트 → 확장 프로그램 → Apps Script로 갑니다. `Code.gs` 내용을 전부 지우고 새 `Code.gs`를 붙여 넣은 뒤 저장합니다.
3. **배포 → 배포 관리 → ✏️(편집) → 버전: 새 버전 → 배포**를 누릅니다.
   - 이렇게 하면 주소(…/exec)가 그대로 유지되므로 `config.js`를 고칠 필요가 없습니다.
   - 「새 배포」를 누르면 주소가 바뀝니다. 그때는 4번처럼 `config.js`에 새 주소를 넣어야 합니다.

화면 파일(html, css, bidder.js, admin.js, client.js)만 고쳤다면 이 단계는 필요 없습니다.

## 4. 다른 서버(구글 시트)에 연결하기

`config.js`에서 `api`만 바꾸면 됩니다.

```js
window.MARKET_CONFIG = {
  api: 'https://script.google.com/macros/s/새주소/exec',
  poll: 12000   // 목록 새로고침 간격(밀리초). 사람이 많으면 15000~20000
};
```

새 구글 시트를 쓰는 경우에는 `apps-script/설치안내.md`의 1~2단계(시트 만들기 → `setup` 실행 → 웹 앱 배포)를 먼저 하세요.
연결이 바뀐 화면을 브라우저가 기억하고 있을 수 있으니 **Ctrl+Shift+R**로 새로고침합니다.

## 5. 고친 화면을 올리기

정적 파일만 있으면 되므로 아래 중 아무 곳에나 올릴 수 있습니다.

- **지금처럼 GitHub Pages**: 저장소 `kird-cyber/kirdwork`의 `market/` 폴더를 고친 파일로 바꿔 올리면 1~2분 뒤 반영됩니다.
  - 주소는 https://kird-cyber.github.io/kirdwork/market/ 입니다.
- **기관 내부 웹 서버, 다른 무료 호스팅(Netlify 등)**: `market` 폴더를 통째로 올리면 됩니다.

파일을 바꿨는데 예전 화면이 보이면, `index.html`·`admin.html` 아래쪽 `<script src="…?v=1">`의 숫자를 하나 올리세요(v=2, v=3…). 그러면 브라우저가 새 파일을 받습니다.

## 6. 바꿔도 되는지 확인 (고급)

Node.js가 있다면 아래 두 가지를 실행해 확인할 수 있습니다.

- `node dev/market/test.js`: 입찰 규칙, 그리고 구글 시트 흉내 환경에서 `Code.gs` 동작을 검사합니다. 끝에 `… pass, 0 fail`이 나오면 정상입니다.
- `node dev/market/e2e.js`: 브라우저 화면 흐름을 검사합니다. Playwright가 필요합니다.

## 주의

- `config.js`의 서버 주소는 화면에서 누구나 볼 수 있는 값입니다. 비밀이 아닙니다.
- **관리자 비밀번호는 코드 어디에도 들어 있지 않습니다.** 비밀번호는 Apps Script의 「프로젝트 설정 → 스크립트 속성 → `ADMIN_PASSWORD`」에만 있습니다.
- 구글 시트의 `입찰` 탭은 손으로 고치지 마세요. 상품과 코드는 관리자 화면에서 고치는 것이 안전합니다.
